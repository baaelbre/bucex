# Research

The active paper workflow is [serra/README.md](serra/README.md).
Scientific choices live in `serra/config`; scripts use the public BUCEX API.
The 1.8.0 common-specification workflow uses private FS locations, repeating
monthly observation scales, constant-in-time GEV shapes and a Gaussian copula,
with optional common innovation hyperpriors. The record ends in August 2026.
Six independent fixed-prior analyses remain available. Existing constant-scale
configurations support reproduction and targeted supplementary comparisons.
General API examples live in `docs/examples`. No conference directories are
required. See the top-level `START_HERE.md` for the exact commands.
