# Additional paper experiments

After the smoke and reference fits in [START_HERE](../START_HERE.md), use the configured prior assessment study with `--stage plan` to inspect model variants and resource budgets. Use `--stage all` to run fits and paired forecast checks. Monthly and seasonal `adequacy.json` files include the constant dispersion candidate; `sensitivity.json` tests hyperprior width and GEV shape; monthly `anchors.json` checks physical prior anchors. Seasonal `constant_copula.json` and `independence.json` provide dependence alternatives. Keep the fitted outputs from each version in separate run directories.
